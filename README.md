# T.I.M.E Platform

This is a monorepo for the T.I.M.E counseling platform.

## Structure

- `frontend/`: React + Vite web application
- `backend/`: FastAPI server for RAG and structured DB operations
- `data/`: Centralized datasets, including SQLite and Chroma Vector DBs
- `scripts/`: Utility scripts (e.g., data migration)
- `docs/`: Project architecture and setup documentation

## Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
# Start the server
```
